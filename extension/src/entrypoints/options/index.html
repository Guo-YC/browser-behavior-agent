敏感字段规则（契约 §1.4 #1、#2）

每行一条正则表达式（大小写不敏感）。元素的 type / name / id / autocomplete / aria-label / placeholder 任一命中，即判定为敏感元素：其 value、key 一律硬丢弃为 ****，且 element.redacted=true。规则在采集层强制执行，原文不落盘。

默认规则：passw|pwd|token|secret|api[_-]?key|apikey|credit|card|cvv|cvc|pin|auth|session[_-]?id|ssn。
