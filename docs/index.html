Why it matters

录屏能回看，但没法让 Agent 学会

现有的浏览器自动化要么靠人写脚本（选择器一改就崩），要么靠模型现场生成（每次都不一样）。这个项目走第三条路：把人的真实操作变成可执行、可验证、可复用的资产。

常见做法的短板

  • 录屏 / 截图只能回放给人看，机器读不懂结构
  • RPA 脚本依赖手写选择器，页面一改就全线失效，还不会告诉你哪里失效了
  • 大模型现场操作浏览器，每次路径都不一致，无法回归验证
  • 行为数据散落在各平台云端，隐私与合规无从控制

这里的做法

  • 采集结果自带 CSS 选择器 + 元素文本 + URL + 时间戳，机器可直接执行
  • 从多条重复轨迹中蒸馏动作链，自动生成前置/后置断言，不只是坐标回放
  • 回放支持 dry_run 预检 / CDP / Playwright 三种模式，逐步断言，失效点位精确报错
  • 数据只落本机 SQLite，敏感字段在采集层就硬丢弃，无外网端口

Architecture

五段式流水线：从浏览器到可执行技能

采集与存储解耦，存储与检索解耦，检索与蒸馏/回放解耦。每一层都能单独使用——你只想查行为就不必碰回放，只想要技能就跳过 MCP。

Capabilities

六个模块，各自可独立使用

每个模块都有独立入口和自检脚本，可以只装其中一个。

01 / COLLECT

全天候静默采集

点击、输入、滚动、导航、标签切换、网络请求全采集。点击精确到元素文本与 CSS 选择器路径，输入记录值而不只是"输入了"。

11 类事件
02 / STORE

按域名自动分表

无需预定义 schema。新域名首次出现即自动建表，FTS5 全文索引同步建立，重启后数据持久，精确重复事件自动去重。

零配置
03 / RETRIEVE

结构化检索

按站点、会话、事件类型、时间窗、URL 片段组合查询；全文检索命中 URL、选择器与元素文本并返回高亮片段。

FTS5 高亮
04 / DISTILL

从重复中提炼技能

用前缀树在多条轨迹中挖掘重复动作链，自动生成 targetUrlPattern 与 text_present / element_present / url_contains 断言，输出技能 JSON。

示范学习
05 / REPLAY

确定性回放

三种模式：dry_run 只做计划与预检、CDP 连本机调试端口、Playwright 真实浏览器。每步执行后逐条断言，失效点位明确报错，绝不静默乱点。

逐步断言
06 / EXPOSE

MCP 一插即用

stdio 与 Streamable HTTP 双传输，10 个中文工具覆盖查询、统计、全文检索、轨迹导出、蒸馏、回放。任意支持 MCP 的 Agent 可直接接入。

双传输

MCP Tools

10 个工具，覆盖完整工作流

典型链路：查我在某站点反复做了什么 → 提炼成技能 → 用技能重跑并验证结果。

list_sites列出已采集网站及事件量
query_behaviors按站点/会话/类型/时间/URL 查行为
query_sessions查询浏览会话
query_requests查询网络请求（已脱敏）
behavior_stats按类型/页面/小时聚合统计
fulltext_searchFTS5 全文检索，带高亮片段
export_trajectory导出轨迹（JSON / Markdown 时间线）
distill_skill从重复轨迹蒸馏可复用技能
list_skills列出已蒸馏技能
trigger_replay按技能执行确定性回放
# 对话里就能这么用
你：查一下我在 example.com 上反复做的操作，把重复的那条提炼成技能
Agent：behavior_stats → query_behaviors → distill_skill（7 步链，匹配率 100%）
你：用这个技能再跑一遍，验证结果对不对
Agent：trigger_replay mode=dry_run → 7/7 PASS；切 cdp → 真机 8/8 PASS

Privacy by design

敏感信息不进入存储层，而不是存在后再删

脱敏发生在采集层第一现场：值在离开页面之前就被替换，落盘时已经不存在。

✳

字段级硬丢弃

密码框、token、密钥、卡号类字段的值一律写为 ****；Authorization、Cookie 等请求头整头剥离；剪贴板只记长度不记内容。正则规则可在 options 页调整。

⌂

纯本地链路

扩展经 Native Messaging 与本地进程通信，不开任何外网端口；HTTP API 只监听 127.0.0.1；数据库留在本机磁盘。

◼

随时可停

options 页提供采集总开关，关闭即停止采集。高噪声事件（如 mousemove）可单独关闭，点击/输入/导航等语义行为不受影响。

Quick start

3 分钟跑通最小链路

不需要浏览器、不需要扩展，先用模拟事件验证整条流水线是否通畅。

# 1) 安装依赖（扩展用 pnpm，其余 npm）
cd extension && pnpm install && cd ..
cd daemon && npm install && cd ..
cd mcp && npm install && cd ..
cd replay/distill && npm install && cd ../..
cd replay/runner && npm install && cd ../..

# 2) 一键端到端验证（期望 PASS=12 FAIL=0）
bash scripts/verify-chain.sh

# 3) 让 Agent 接入（stdio 方式）
{
  "browser-behavior": {
    "type": "local",
    "command": ["node", "/绝对路径/browser-behavior-agent/mcp/index.js"],
    "enabled": true
  }
}

真机采集（可选）

  • pnpm build 构建扩展，产物在 extension/.output/chrome-mv3
  • chrome://extensions 开发者模式 → 加载已解压的扩展程序
  • Linux：bash scripts/setup.sh --extension-id <ID> 一条命令完成注册与守护进程
  • Windows：scripts\install-native-host.ps1 -ExtensionId <ID>

运行环境

  • Node.js 20+，业务代码全平台同一份
  • Linux：systemd 用户单元自启
  • Windows：任务计划程序或 NSSM，注册表写 HKCU 免管理员
  • 数据库须放本地磁盘，勿放网络挂载/同步盘
